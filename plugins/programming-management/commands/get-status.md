# /get-status — where things actually stand

Pull from the plane and the board, plus whatever leads have reported this session. Six short fields, in
order, each a few lines at most — this is a status check, not a milestone report.

1. **Done** — what finished since the last report.
2. **Problems handled** — what went wrong and how it got resolved, or is being resolved.
3. **Where the time went** — which milestones or tasks actually took the work, in plain terms.
4. **Waiting on you** — the open decision count; point at `/decisions` if there are any.
5. **ETA** — an honest estimate for what's still running, not a guess dressed up as a number.
6. **Left to do** — what's still ahead on the plane and the board.

No milestone-by-milestone detail, no per-task breakdown — that's what the board itself is for. This is
the shape a person reads in one pass.
