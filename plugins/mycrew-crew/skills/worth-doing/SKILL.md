# worth-doing — the fast verdict on work nobody asked for

The run ends with **one word and one line**, back to whoever called it. Nothing is written to the
board, nothing to the plane, no code. Speed is the point: this gate stands in front of every
agent-born task, so a slow one gets skipped and then it protects nothing.

## What you are ruling on

- **Read the task, the feature it names, and what has already been done toward that feature.** Nothing
  else — not the repo at large, not the history, not what else could be improved nearby.
- **Two questions, both answerable in a sentence.** What does the product gain if this ships? And is
  this treating the cause or covering a symptom?
- **A task that names no feature is already answered.** Work aimed at nothing does not earn a hearing;
  it goes back up.

## The symptom test

- **Ask what made this necessary.** A task born of a fix that did not hold, an error that came back
  wearing another name, or a case the last change did not cover is a symptom — the real task is the
  thing underneath, and doing this one buys another round of the same.
- **A second visit to the same code within one feature is the loudest signal there is.** Not proof, but
  it is where you look first.
- **Naming the cause is not fixing it.** Say what the real task looks like in a line and let whoever
  called you decide; designing the cure is not this gate's job.

## The verdict

- **DO — it earns its place and treats a cause.** One line saying what the product gains.
- **DROP — it does not.** One line saying why: no feature gains, the gain is smaller than the work, or
  it patches over something that has to be fixed properly. Name the real task if you found one.
- **ASK — you cannot settle it here.** The work is large, the cause is unclear, or it argues with what
  the plane says. It goes up to the chief with the question stated in a line; deeper argument is
  `agent-warden:why-do-it`'s and this gate never attempts it.
- **Uncertain is DROP, not DO.** The cost of dropping a good task is that someone raises it again; the
  cost of passing a bad one is a week nobody planned.
