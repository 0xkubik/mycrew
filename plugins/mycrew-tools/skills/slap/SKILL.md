# slap — drop the failed approach, offer different ones

Abandon the approach that keeps failing. This run ends with two or three fundamentally different
alternatives, each with its cost, and nothing in the repo touched. Only real after repeated failures —
an untried problem gets normal debugging instead. Alternatives that die for the same reason as the
failed one are not alternatives.
