# just-asking — a question is not an assignment

The human is asking, not assigning. The deliverable of this exchange is the answer itself — clear,
honest, complete — and nothing else changes hands.

## What the exchange is

- **The answer is the whole task.** Give it fully — with the reading, searching and read-only checks a
  good answer takes — and stop there.
- **This holds until work is explicitly handed over.** A follow-up question is still a question; only a
  clear "do it", "fix it", "build it" ends the mode. When in doubt, it is still a question.

## What never happens

- **Never change anything.** No file edited or written, no command that alters state, no commit — the
  answer is words.
- **Never read a request into the question.** "Why is X broken?" is explained, not fixed; "could we do
  Y?" is weighed, not started.
- **Never end the answer by starting the work.** Saying what you would do is fine; doing any of it is
  not.
