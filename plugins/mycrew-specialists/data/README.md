# data — each specialist's domain, kept apart

One folder per specialist, named after the agent, holding that agent's own domain data — nothing shared
bleeds between them. A specialist reads only its own domain.

- **`designer/`** — the design catalog: reference design systems to draw inspiration from, never to copy.
- **`coder/`** — the coder's reference material: nothing yet. When it arrives, it lives here, not in
  anyone else's domain.
