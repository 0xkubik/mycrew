# /warden-start — pick the watch back up

The run ends with the eyes armed and one short account of the board as it stands: what is in
progress, and anything already breaking a rule. Already armed → say so, change nothing, and stop.

- **Open the watch the way the character opens it** — `agent-warden:warden`'s own opening, step for
  step. Nothing about arming is restated here.
- **A restart is never silent.** Before the first new verdict, the journal takes the window the watch
  was down for. A gap nobody wrote down reads afterwards as a stretch where nothing happened.
- **What was missed comes back as state, not as history.** The eyes report what is broken on the board
  now, not every move made while they were down — a card fixed during the gap is not news. Say plainly
  that the gap was not replayed.
- **Ending armed is the only success.** Eyes that could not be armed is a failure to report in one
  line, not a watch quietly standing down.
