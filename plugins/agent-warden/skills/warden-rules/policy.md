# The policy — what each finding earns

One row per finding, one column per move. A tick is a duty, not a permission: land on that row and the
move happens. A cross is a prohibition: the move is not made on that finding, however reasonable it
feels at the time. The judgment is in choosing the row and never in choosing the cell — that is what
makes a keeper predictable enough to be trusted, and what stops a hard call from quietly becoming a
silent one. A finding with no row of its own earns a journal line and nothing else, and where more than
one row fits, every duty across all of them applies. The table is the tunable: a decision that changes
what a finding earns is written here as a changed cell, never carried in someone's head.

| finding | log | ask | flag | human | case |
| --- | :-: | :-: | :-: | :-: | :-: |
| a card moved and nothing is wrong with it | ✓ | ✗ | ✗ | ✗ | ✗ |
| UNGATED — agent-born work in progress that never passed the gate | ✓ | ✓ | ✗ | ✗ | ✗ |
| NOPLAN — a card serving no feature | ✓ | ✓ | ✗ | ✗ | ✗ |
| EARLYDONE — done with criteria still unchecked | ✓ | ✓ | ✗ | ✗ | ✗ |
| STALE — in progress and untouched too long | ✓ | ✓ | ✗ | ✗ | ✗ |
| in progress, and no live worker exists for it | ✓ | ✓ | ✗ | ✗ | ✗ |
| the same feature entered for the third time | ✓ | ✓ | ✗ | ✗ | ✗ |
| a lead answered the question | ✓ | ✗ | ✗ | ✗ | ✗ |
| the same rule broken a second time | ✓ | ✗ | ✓ | ✗ | ✓ |
| a rule broken while the first question hangs unanswered | ✓ | ✗ | ✓ | ✗ | ✓ |
| a flagged card kept moving | ✓ | ✗ | ✓ | ✓ | ✗ |
| the human overrode a flag | ✓ | ✗ | ✗ | ✗ | ✗ |
| the board or the watcher is gone | ✓ | ✗ | ✗ | ✓ | ✗ |
| MORE — findings this tick beyond the cap | ✓ | ✗ | ✗ | ✗ | ✗ |

**log** a journal entry · **ask** a question to the card's lead · **flag** a stop on that card ·
**human** it goes to them · **case** a case file is opened

A flag always follows a question that was already asked; nothing is flagged on first sight.
